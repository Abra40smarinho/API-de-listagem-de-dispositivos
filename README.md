O projeto consiste em uma arquitetura para monitoramento de dispositivos via Home Assistant.
A instalação é simples, utiliza-se o repositório para colocar no stack do portainer do cliente, as chaves do .env da stack e o site fica na porta 8088 do dispositivo.
O intuito é para a manutenção de dispositivos que se encontram "indisponíveis", verificando caso o erro pode ser de internet ou do próprio dispositivo em si, melhorando a qualidade do atendimento ao cliente.
